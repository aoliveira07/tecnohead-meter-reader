# Homologação

## Bancada

Só marcar como **PASSOU** após observar no ESP32 real: bytes gerados por TTL 3,3 V, mesma ordem no `.bin`, controles de framing aplicados sem reflash, pausa/limpeza/marcação, persistência após reboot e sessão incompleta detectada.

## Home Assistant

Só marcar como **PASSOU** após abrir o dashboard em desktop e celular, ver o dispositivo ESPHome online, operar os selects e switches, abrir o console Ingress e baixar os três formatos.

## Nansen

Permanece **PENDENTE / NÃO EXECUTADO** neste projeto. A validação física depende de autorização para uso da interface RS232 da CPFL e de interface isolada aprovada. Mesmo sob autorização, a primeira etapa seria apenas escuta RX e o resultado correto pode ser “sem tráfego espontâneo observado”.

Nenhum número de série, IP privado, credencial, captura do cliente ou resultado físico é publicado neste repositório.
